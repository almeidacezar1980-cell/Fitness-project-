# FitProgress Cezar v2

Aplicativo web instalável (PWA) para acompanhamento pessoal de treino e progresso físico.

## Recursos
- Dashboard com peso atual e treinos concluídos
- Treinos de segunda, quarta e sexta
- Registro de séries, repetições e cargas
- Cronômetro de descanso
- Registro de peso e medidas
- Gráfico de evolução de peso
- Fotos de progresso armazenadas localmente
- Controle diário de água e proteína
- Backup e restauração em JSON, incluindo fotos
- Tema claro/escuro
- Funciona offline após a primeira abertura
- Instalável no Android

## Publicar no GitHub Pages
1. Envie o conteúdo desta pasta para a raiz de um repositório GitHub.
2. No repositório, abra Settings > Pages.
3. Em Build and deployment, escolha "Deploy from a branch".
4. Selecione branch `main` e pasta `/ (root)`.
5. Salve e aguarde o link do GitHub Pages.

## Privacidade
Os dados ficam no navegador do aparelho. O aplicativo não envia informações para servidor externo.
